1. Sequencia de Uso do Sistema

O CRM Sucata foi projetado para guiar o usuario por uma sequencia logica de telas, desde o primeiro acesso ate as operacoes diarias de gestao. Abaixo estao os dois fluxos principais: o do usuario comum (sucateiro, comprador, analista) e o do administrador.

1.1 Fluxo Principal - Usuario Comum

Passo a Passo

Tela 1: Registro - Usuario preenche nome, e-mail, CPF, telefone e senha forte.

▼

Tela 2: Cadastro Pendente - Sistema informa: "Aguardando aprovacao do administrador."

▼

(Admin aprova em outro fluxo)

▼

Tela 3: Login - Usuario insere e-mail e senha validos.

▼

Tela 4: Dashboard - Painel com KPIs, ranking e alertas. Acesso a todos os modulos via sidebar.

▼

Modulos disponiveis:

  • Oportunidades - Cadastrar novos fornecedores, acompanhar funil de vendas.
  • Visitas - Agendar, confirmar, concluir com validacao GPS.
  • Inteligencia de Mercado - Registrar precos da concorrencia e tendencias.
  • Relatorios - Visualizar pipeline, taxas de conversao (se gerente+).
  • Configuracoes - Alterar perfil, senha e preferencias.
▼

Em qualquer momento: Botao Sair na sidebar encerra a sessao e retorna ao Login.

1.2 Fluxo do Administrador

Passo a Passo do Admin

Tela 1: Login - Admin acessa com credenciais.

▼

Tela 2: Dashboard - Mesmo painel, mas com acesso aos modulos administrativos.

▼

Tela 3: Aprovacao de Usuarios - Visualiza lista de cadastros pendentes. Cada linha tem botoes Aprovar (com escolha de perfil) e Rejeitar (com motivo).

▼

Tela 4: Usuarios - Gestao completa: editar, suspender, reativar, alterar perfil, resetar senha.

▼

Tela 5: Configuracoes - Admin tambem pode alterar suas proprias configuracoes.

2. Telas Publicas (Sem Autenticacao)

Estas sao as unicas telas acessiveis sem login. Servem de porta de entrada para novos usuarios.

2.1 Tela de Login - /login

Tela: Login

Descricao

Tela inicial do sistema. Fundo em gradiente azul escuro (#1a1a2e ate #0f3460). Card central branco com sombra. Logo "S" em quadrado arredondado. Campos de e-mail e senha com icones a esquerda.

Botoes e Acoes

BotaoTexto na TelaAcaoComando / Funcao
Primario"Entrar"Autenticar usuarioChama authService.login(email, password). Valida JWT. Se sucesso, redireciona para /dashboard.
Link"Cadastre-se"Ir para registroNavega para /register.
Link"Esqueci a senha"RecuperacaoAbre fluxo de reset de senha (futuro).

Mensagens de Erro

  • "Cadastro aguardando aprovacao" - Status = PENDENTE. Botao "Voltar ao Login".
  • "Cadastro rejeitado" - Status = REJEITADO. Orienta contato com admin.
  • "Conta suspensa" - Status = SUSPENSO. Orienta contato com admin.
  • "Conta bloqueada por 30 min" - 5 tentativas falhas. Bloqueio temporario.
  • "E-mail ou senha incorretos" - Credenciais invalidas. Mostra tentativas restantes.

4.3.1 Aba: Informacoes

Botoes e Acoes

"Cancelar" - Descarta alteracoes e restaura valores originais. Comando: Reseta formulario React Hook Form.
"Salvar" - Envia dados editados para o backend. Comando: Chama updateOpportunity(id, data). Invalida cache. Toast "Dados salvos".

4.3.2 Aba: Contatos

Botoes e Acoes

"Adicionar Contato" - Abre modal para cadastrar nova pessoa. Comando: Abre modal com createContact(data).
"Editar" (por contato) - Altera dados do contato. Comando: updateContact(id, data).
"Excluir" (por contato) - Remove contato. Comando: deleteContact(id) com confirmacao.

4.3.3 Aba: Visitas

Botoes e Acoes

"Agendar Visita" - Abre modal de agendamento. Comando: Navega para /visits com pre-selecao da oportunidade.

4.3.4 Aba: Fotos

Botoes e Acoes

"Adicionar Foto" - Upload de imagem com categoria. Comando: uploadPhoto(opportunityId, file, category).
"Excluir" (por foto) - Remove imagem. Comando: deletePhoto(id) com confirmacao.

4.3.5 Aba: Timeline

Apenas visualizacao. Linha do tempo automatica gerada pelo sistema. Mostra data, usuario, acao e detalhes. Sem botoes de acao.
