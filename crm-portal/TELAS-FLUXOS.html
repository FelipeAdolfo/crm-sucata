1. Sequência de Uso do Sistema

O CRM Sucata foi projetado para guiar o usuário por uma sequência lógica de telas, desde o primeiro acesso até as operações diárias de gestão. Abaixo estão os dois fluxos principais: o do usuário comum (sucateiro, comprador, analista) e o do administrador.

1.1 Fluxo Principal — Usuário Comum

Passo a Passo

Tela 1: Registro → Usuário preenche nome, e-mail, CPF, telefone e senha forte.

↓

Tela 2: Cadastro Pendente → Sistema informa: "Aguardando aprovação do administrador."

↓

(Admin aprova em outro fluxo)

↓

Tela 3: Login → Usuário insere e-mail e senha válidos.

↓

Tela 4: Dashboard → Painel com KPIs, ranking e alertas. Acesso a todos os módulos via sidebar.

↓

Módulos disponíveis:

  • Oportunidades → Cadastrar novos fornecedores, acompanhar funil de vendas.
  • Visitas → Agendar, confirmar, concluir com validação GPS.
  • Inteligência de Mercado → Registrar preços da concorrência e tendências.
  • Relatórios → Visualizar pipeline, taxas de conversão (se gerente+).
  • Configurações → Alterar perfil, senha e preferências.
↓

Em qualquer momento: Botão Sair na sidebar encerra a sessão e retorna ao Login.

1.2 Fluxo do Administrador

Passo a Passo do Admin

Tela 1: Login → Admin acessa com credenciais.

↓

Tela 2: Dashboard → Mesmo painel, mas com acesso aos módulos administrativos.

↓

Tela 3: Aprovação de Usuários → Visualiza lista de cadastros pendentes. Cada linha tem botões Aprovar (com escolha de perfil) e Rejeitar (com motivo).

↓

Tela 4: Usuários → Gestão completa: editar, suspender, reativar, alterar perfil, resetar senha.

↓

Tela 5: Configurações → Admin também pode alterar suas próprias configurações.

2. Telas Públicas (Sem Autenticação)

Estas são as únicas telas acessíveis sem login. Servem de porta de entrada para novos usuários.

2.1 Tela de Login — /login

Tela: Login

Descrição

Tela inicial do sistema. Fundo em gradiente azul escuro (#1a1a2e → #0f3460). Card central branco com sombra. Logo "S" em quadrado arredondado. Campos de e-mail e senha com ícones à esquerda.

Botões e Ações

BotãoTexto na TelaAçãoComando/Função
Primário"Entrar"Autenticar usuárioChama authService.login(email, password). Valida JWT. Se sucesso, redireciona para /dashboard.
Link"Cadastre-se"Ir para registroNavega para /register.
Link"Esqueci a senha"RecuperaçãoAbre fluxo de reset de senha (futuro).

Mensagens de Erro

  • "Cadastro aguardando aprovação" — Status = PENDENTE. Botão "Voltar ao Login".
  • "Cadastro rejeitado" — Status = REJEITADO. Orienta contato com admin.
  • "Conta suspensa" — Status = SUSPENSO. Orienta contato com admin.
  • "Conta bloqueada por 30 min" — 5 tentativas falhas. Bloqueio temporário.
  • "E-mail ou senha incorretos" — Credenciais inválidas. Mostra tentativas restantes.

4.3.1 Aba: Informações

Botões e Ações

"Cancelar" — Descarta alterações e restaura valores originais. Comando: Reseta formulário React Hook Form.
"Salvar" — Envia dados editados para o backend. Comando: Chama updateOpportunity(id, data). Invalida cache. Toast "Dados salvos".

4.3.2 Aba: Contatos

Botões e Ações

"Adicionar Contato" — Abre modal para cadastrar nova pessoa. Comando: Abre modal com createContact(data).
"Editar" (por contato) — Altera dados do contato. Comando: updateContact(id, data).
"Excluir" (por contato) — Remove contato. Comando: deleteContact(id) com confirmação.

4.3.3 Aba: Visitas

Botões e Ações

"Agendar Visita" — Abre modal de agendamento. Comando: Navega para /visits com pré-seleção da oportunidade.

4.3.4 Aba: Fotos

Botões e Ações

"Adicionar Foto" — Upload de imagem com categoria. Comando: uploadPhoto(opportunityId, file, category).
"Excluir" (por foto) — Remove imagem. Comando: deletePhoto(id) com confirmação.

4.3.5 Aba: Timeline

Apenas visualização. Linha do tempo automática gerada pelo sistema. Mostra data, usuário, ação e detalhes. Sem botões de ação.
